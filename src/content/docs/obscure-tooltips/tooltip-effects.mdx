## [Rim Light Effect](https://github.com/ObscuriaLithium/obscure-tooltips/blob/master/common/src/main/java/dev/obscuria/tooltips/client/tooltip/element/effect/RimLightEffect.java)

<CodeBlock label="JSON Example">
```json
{
  "type": "obscure_tooltips:rim_light",
  "outer_palette": {
    "top_left": "#30f00fff",
    "top_right": "#30f00fff",
    "bottom_left": "#30f00fff",
    "bottom_right": "#30f00fff"
  },
  "inner_palette": {
    "top_left": "#00ff00ff",
    "top_right": "#00ff00ff",
    "bottom_left": "#00ff00ff",
    "bottom_right": "#00ff00ff"
  }
}
```
</CodeBlock>

## [Inward Particle Effect](https://github.com/ObscuriaLithium/obscure-tooltips/blob/master/common/src/main/java/dev/obscuria/tooltips/client/tooltip/element/effect/InwardParticleEffect.java)

See [Particles](#particles) for more details.

<CodeBlock label="JSON Example">
```json
{
  "type": "obscure_tooltips:inward_particle",
  "particle": {
    "type": "obscure_tooltips:line",
    "center_color": "#80ff80ff",
    "edge_color": "#00aa40aa",
    "transform": {
      "offset": [ 0.0, 0.0, 0.0 ],
      "scale": 1.0,
      "rotation": 0.0
    }
  }
}
```
</CodeBlock>
